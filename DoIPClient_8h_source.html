22 /**
23  * @brief DoIP client implementation for diagnostic communication
24  *
25  * This class implements a DoIP (Diagnostics over IP) client according to ISO 13400.
26  * It handles both UDP vehicle discovery and TCP diagnostic communication.
27  *
28  * @note This is legacy code kept for testing purposes only. Not actively maintained.
29  *
30  * The client supports:
31  * - UDP vehicle discovery (announcements and identification requests)
32  * - TCP routing activation and diagnostic messaging
33  * - Alive check handling
34  * - Automatic reconnection
35  *
36  * @warning Thread-safe for enqueueing messages, but TCP/UDP threads should not be
37  * accessed concurrently with start/stop operations.
38  */
